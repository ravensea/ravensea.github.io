GitHub 趋势日报 2026-10-29

Author: Ravensea Date: 2026年10月29日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：jamakr4/MG4-360-Camera-App · 39 star · 首次收录
    这是面向名爵 MG4 EV（AAOS 9、2026 款改款前车型）的社区改装应用，用 Java 等实现，旨在替换原厂启动器叠加层，解决原车 360° 影像在高速下自动关闭、全屏接管等问题。它提供特斯拉风格转向灯摄像头叠加、平铺视图、盲区监测、行车记录仪和数字后视镜等功能，并取消原速度阈值自动关闭限制。

  • 电子：tlamy/P2Pro-Viewer · 1 star · 首次收录
    这是一个面向 InfiRay P2 Pro 热成像模块的跨平台开源查看器与 API，基于逆向得到的通信协议实现，以避免依赖厂商预编译库。项目使用 C++ 编写，支持 macOS、Linux 和 Windows，并借助 SDL2、libusb 及平台原生视频接口完成控制与视频流处理。

  • 机械：FerdiCildiz/pocket-plus · 14 star · 持续跟踪
    Pocket+ 是一款免费的 macOS 应用，用于将 DJI Osmo Pocket 2、3、4 和 4P 作为桌面摄像头进行控制，可录制、拍照、操控云台、变焦并跟踪人脸。它主要解决 DJI Mimo 没有 Mac 版的问题，让 Pocket 通过 USB-C 连接 Mac 后实现实时预览、云台与变焦控制、人脸跟踪及直接录制到 Mac。其能力亮点包括 H.264/HEVC 录制与照片拍摄、免费版最高 1080p 而 Pro 版最高 4K、场景保存与快速切换、自动构图、竖屏视频、LUT 色彩外观、广角镜头校正以及重连后返回上次位置等。

  • 算法：neuromorphicsystems/neuromorphic-drivers · 41 star · 持续跟踪
    Neuromorphic Drivers 是一个用 Rust 实现、同时提供 Python 和 Rust 接口的库，用于实时与 USB 和以太网事件相机交互，兼容 Linux、macOS 和 Windows 的主要架构，目标是支持尽可能多的商用设备。它本身不包含处理算法，而是作为采集层与其他库组合构建实时处理流水线，并自行实现相机的 USB 与以太网协议，不依赖 Metavision、libcaer 或 dv-processing，从而便于跨平台支持并提供轻量的预编译 Python wheel。

视觉、世界模型与运控

  • 世界模型：AlayaLab/AlayaWorld · 801 star · 首次收录
    AlayaWorld 是 Alaya Lab 开源的全栈交互式长时程世界模型，用 Python 实现，面向长时程、可交互视频世界生成的研究与实验。它主要解决长时程生成中的记忆一致性以及实时交互控制问题，支持实时相机控制、生成过程中切换提示词，并提供浏览器内可玩的交互演示。项目已开源训练与推理代码、预训练权重及部分训练数据，采用自回归生成并结合 DMD 等技术。

  • 视觉运控：HCPLab-SYSU/Embodied_AI_Paper_List · 2189 star · 持续跟踪
    这是中山大学HCP Lab与鹏城实验室维护的具身智能论文列表与资源仓库，配套其发表于IEEE/ASME Transactions on Mechatronics 2025的综述《Aligning Cyber Space with Physical World: A Comprehensive Survey on Embodied AI》。该仓库面向具身智能方向的研究者，汇总代表性具身机器人与仿真器工作，并围绕具身感知、具身交互、具身智能体和仿真到现实迁移四个研究目标整理前沿方法、范式与数据集，同时探讨多模态大模型与世界模型在虚拟和真实具身智能体中的作用。仓库还提供综述PDF与arXiv链接，并欢迎同行通过issue、邮件或pull request提出改进建议。

视觉算法

  • 理解：Blaizzy/mlx-vlm · 5689 star · 持续跟踪
    MLX-VLM 是一个基于 MLX 的 Python 包，用于在 Mac 上进行视觉语言模型（VLM）以及支持音频和视频的 Omni 模型的推理与微调。它面向需要在本地 Mac 环境运行和调优这类模型的研究者，提供命令行界面、Gradio 聊天界面、FastAPI 服务端以及 Python 脚本等使用方式。材料列出的能力亮点包括投机解码（DFlash、DFlash2、DSpark、Gemma 4 MTP、EAGLE-3 等）、连续批处理、自动前缀缓存、KV 缓存量化、1-bit 仿射推理、多图像对话、视觉特征缓存、TurboQuant KV 缓存和分布式推理，并包含针对多种模型的专门文档。

  • 生成：FlyMyAI/flymyai-lora-trainer · 770 star · 首次收录
    这是 FlyMy.AI 开源的 Python 实现，用于为 Qwen-Image、Qwen-Image-Edit 和 FLUX.1-dev 模型训练 LoRA（低秩适配）层，面向需要高效微调文生图模型的研究者与开发者。项目支持基于 LoRA 的高效微调、与 Hugging Face diffusers 兼容、通过 YAML 配置训练，并提供基于控制的图像编辑 LoRA 训练以及 FLUX 的高质量人像与角色训练能力。项目仍在开发完善中，基础训练功能已可用，性能优化与测试覆盖尚在推进。

3D 与电子设计

  • 打印与建模：SSSSSia/CadAgent · 8 star · 首次收录
    CadAgent 是一个基于 LLM Agent 的 FreeCAD 工作台插件，面向需要用自然语言生成和修改 3D 机械模型的研究者与设计者，支持中英文描述零件并自动规划建模。其核心是 ReAct 智能体循环：LLM 生成 CadQuery 风格链式代码，经内置翻译层直接调用 FreeCAD Part API 执行，再分析结果并自纠错迭代。亮点包括 CAD 质量门禁与分类化修复反馈、参数化设计、多文档装配、几何特征分析、视口截图与参考图分析、撤销回滚及 STEP/IGES/STL/OBJ 导出。

量化交易

  • 综合：vnpy/vnpy · 46132 star · 持续跟踪
    VeighNa（vnpy）是基于 Python 的开源量化交易系统开发框架，面向私募基金、证券与期货公司等机构及量化研究者，支持在 Windows、Linux、macOS 上进行策略与模块的二次开发。4.0 版本新增 vnpy.alpha 模块，提供多因子机器学习策略的一站式开发、投研与实盘交易能力，涵盖因子特征工程（含 Alpha 158 因子集）、标准化模型训练（Lasso、LightGBM、MLP）、截面与时序策略构建以及集成回测的投研流程管理。
