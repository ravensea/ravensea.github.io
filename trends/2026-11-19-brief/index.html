GitHub 趋势日报 2026-11-19

Author: Ravensea Date: 2026年11月19日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：erik-sutton95/OpenPocketCine · 428 star · 持续跟踪
    OpenPocketCine 是一个用 Swift 开发的开源 iOS 与 Android 现场监视器应用，面向使用 DJI Osmo Pocket 系列相机的拍摄者。它把专业示波器、曝光辅助、相机与云台控制、回放以及 LUT 导出等功能集成到手机上，作为外接现场监视工具使用。项目以 Apache 2.0 许可开源，并提供 iPhone/iPad 的 TestFlight 测试与 Android 测试版渠道。

  • 电子：DamageZedd/Zone-Bodycam · 1 star · 首次收录
    这是面向《S.T.A.L.K.E.R. Anomaly / G.A.M.M.A.》的 C 语言实现的胸前佩戴式执法记录仪视角模组，为玩家提供鱼眼镜头、随身体动作滞后与晃动的胸挂运动感，以及游戏内日期时间、录制计时和可见友方 NPC 标记等叠加信息。其镜头依赖较新版本的 Modded exes 或 Slop-Ray 引擎提供的 Shader Bus，旧版引擎下镜头关闭但叠加层与标记仍可用，并支持 4:3、16:9、21:9 和 32:9 屏幕比例，各项效果可在 MCM 中调节或关闭。

  • 机械：simplefoc/Arduino-SimpleFOCShield · 634 star · 首次收录
    这是面向中功率 FOC 应用的开源低成本 BLDC/步进电机驱动板，与 SimpleFOC 库配合，为 Arduino UNO 及标准 Arduino 排针板卡提供即插即用的 BLDC 电机硬件控制方案。其亮点包括最高 10A 双向在线电流检测（INA240 电流检测放大器）、集成 8V 稳压器、电源电压检测、可堆叠双电机运行、编码器/霍尔与 I2C 接口可配置上拉，以及 QWIIC/STEMMA 和 SPI 连接器。

  • 算法：fecusoooo/spike-camera-image-reconstruction · 1 star · 首次收录
    这是一个面向脉冲相机图像重建的计算摄影课程项目，复现了 BSF 方法，并在真实录制数据与公开脉冲数据上将其与 TFI、TFP、SSML 三种方法进行对比。项目使用 Spike M1K40-H2-Gen3 相机采集脉冲流，梳理了该相机 .dat 格式所需的数据解码与预处理流程，并对 BSF 的 MODF 特征融合阶段尝试引入物理先验门控进行探索性修改。

视觉、世界模型与运控

  • 世界模型：NVIDIA/cosmos · 12406 star · 持续跟踪
    NVIDIA Cosmos 是一个面向物理 AI 的开放平台，提供世界模型、数据集和工具，供开发者构建面向机器人、自动驾驶和智能基础设施等场景的物理 AI 应用。其核心是 Cosmos 世界基础模型家族，强调在同一模型体系中实现感知、推理、模拟与行动，并支持物理感知生成、世界场景迁移、动作策略执行和自动驾驶仿真等能力。材料还显示其提供模型集合、技术报告、快速上手与示例手册等资源，便于研究者进一步了解和使用。

  • 视觉运控：RainBowLuoCS/Gamer · 731 star · 首次收录
    Gamer 是一个面向长时程实时游戏智能体的通用视觉-语言-动作基础模型官方实现，采用端到端架构将感知、记忆管理与多步推理结合，支持在传统 2D 图形界面和复杂 3D 模拟环境中交互。其共享的训练与部署流程面向需要长时程任务处理的研究者与游戏智能体开发者。

视觉算法

  • 理解：Neywa-Labs/mlx-vlm · 5861 star · 持续跟踪
    MLX-VLM 是一个基于 MLX 的 Python 包，用于在 Apple Silicon Mac 上本地运行和微调视觉语言模型，支持文本、图像、视频和音频输入。它面向需要在本地进行多模态模型推理与微调的研究者，提供命令行、Gradio 聊天界面和 FastAPI 服务等使用方式，并包含投机解码、连续批处理、前缀缓存、KV 缓存量化、视觉特征缓存和分布式推理等能力。

  • 生成：fujc683/seedance-2-5-flash-camera-movements · 209 star · 首次收录
    这是一个面向文生视频创作者的相机运动提示词参考仓库，整理了 12 种值得掌握的镜头运动（如推拉、环绕、跟拍、升降、手持、甩镜等），并为每种运动给出可直接复制的提示短语及适用场景。它主要解决文生视频模型在未指定镜头时会自行选择运动、导致画面不可控的问题，同时提供提示词模板（主体动作、镜头运动、镜头、光线、节奏）和常见错误修正建议，帮助研究者更稳定地控制生成视频的镜头语言。

3D 与电子设计

  • 打印与建模：armpro24-blip/cad-cae-copilot · 98 star · 持续跟踪
    CAD/CAE Copilot 是一个面向 AI 智能体的 AI 原生 CAD/CAE/CAX 工作台，用 Python 实现，支持从工程规格文本生成可编辑、可验证的真实 CAD 模型并延伸到 CAE 流程。它主要解决 AI CAD 工具只停留在生成图片、无法产出可复现工程产物的问题，面向需要文本转 CAD/CAE 的研究者与工程用户。关键技术能力包括基于 build123d/OpenCASCADE 的真实几何、STEP/STL/GLB 导出、命名零件与可编辑参数、稳定拓扑指针、确定性评审，以及 MCP 服务器工具，并将全部产物保存在可复现的 .aieng 包中。

量化交易

  • 综合：FinancialComputingUCL/LOBFrame · 263 star · 首次收录
    LOBFrame 是一个面向大规模限价订单簿（LOB）数据处理的开源 Python 代码库，旨在为相关研究提供统一、可复现的实验框架。它覆盖数据变换与处理、训练验证测试以及通过交易模拟评估模型输出质量的完整流程，并提供超快的训练与测试实现。该框架支持集成新模型以保持可扩展性，配套复现两篇 LOB 预测研究论文的实验教程，代码基于 LOBSTER 数据。
