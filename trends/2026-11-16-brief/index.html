GitHub 趋势日报 2026-11-16

Author: Ravensea Date: 2026年11月16日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：rhoenschrat/DJI-Remote · 36 star · 首次收录
    DJI-Remote 是一个用 C 语言编写的蓝牙遥控器项目，可同时控制最多三台 DJI Osmo Action/360 相机，面向多机位骑行拍摄等需要可靠、免分心操控的场景。它支持开始/停止录制、高光标记、休眠唤醒与休眠中快照、模式切换、开机自动扫描重连、多机动作协同，并向所有已连接相机转发实时 GPS 数据。项目基于 M5Stack Basic V2.7（ESP32）和 Waveshare ESP32-S3-LCD-1.9（ESP32-S3），使用 ESP-IDF 与 LVGL 9.5.0 实现硬件加速界面，并可选配 GPIO 外接按键。

  • 电子：amd/mini-isp · 152 star · 首次收录
    Mini-ISP 是面向 AMD FPGA、完全用 Verilog RTL 在可编程逻辑中实现的小型开源图像信号处理器，用于把相机传感器 RAW 数据转换为可供显示、后续处理或存储的图像，为缺少硬化 ISP 的 FPGA 与 SoC 提供 ISP 方案。其设计目标是在占用尽量少 PL 资源的前提下实现高吞吐、低延迟，并保证输出结果正确、图像质量对多数应用可接受。

  • 机械：e-flare/toolkit · 14 star · 首次收录
    该仓库是面向事件相机镜头眩光去除的研究工具包，基于 Python 实现，对应论文《Learning to Remove Lens Flare in Event Camera》。它主要解决事件相机受镜头眩光影响而产生严重退化的问题：这种光学伪影在事件流中形成复杂的时空畸变，此前基本被忽视。材料显示其亮点是提出首个系统性的事件相机镜头眩光去除框架，并先通过推导基于物理的前向模型来建立理论基础，刻画非线性抑制过程。

  • 算法：rmcao/noise2image · 21 star · 首次收录
    这是论文《Noise2Image: Noise-Enabled Static Scene Recovery for Event Cameras》的官方实现与数据仓库，面向事件相机静态场景恢复研究，提供噪声事件到图像的转换代码。仓库包含噪声事件到图像数据集、基于实验数据训练的预训练权重，以及推理、实验数据训练评估和合成数据训练三类脚本，并支持极性、像素分箱、时间分箱与积分时间等参数配置。

视觉、世界模型与运控

  • 世界模型：Thinklab-SJTU/Bench2Drive · 1979 star · 首次收录
    Bench2Drive 是面向端到端自动驾驶（E2E-AD）的闭环基准与数据集，由世界模型强化学习专家 Think2Drive 增强，主要供自动驾驶研究者训练和评测端到端模型。其 0.0.4 版本强调数据分布，提供在 44 个场景×25 条路线（共 1,100 条路线）上严格均匀采集的训练集，新增 3D 占用模态，并设置 220 条路线的独立验证集以支持更可靠的评估。

  • 视觉运控：terminators2025/RealMirror · 785 star · 首次收录
    RealMirror 是一个综合性的开源具身智能 VLA 平台，面向具身智能与机器人学习研究者，提供遥操作、数据采集与模型评测的一体化工具链。平台开源了 Isaac Sim 侧控制栈与 XR-Linker WebXR 传输的完整遥操作方案，并支持基于 PICO 的手势遥操作；同时提出 Seed2Scale 大规模上肢轨迹自动生成方案，配套视觉物理回放工具与量化评估结果。

视觉算法

  • 理解：MMMU-Benchmark/MMMU · 601 star · 首次收录
    该仓库是 MMMU 与 MMMU-Pro 两篇论文的官方评测代码，面向研究者评估多模态模型在需要大学水平学科知识与审慎推理的多学科任务上的表现。MMMU 包含约 1.15 万道来自考试、测验和教材的多模态题目，覆盖六大核心学科、30 个学科和 183 个子领域，涉及图表、示意图、地图、表格、乐谱和化学结构等 32 种异构图像类型；MMMU-Pro 则是更稳健的评测版本。仓库提供相应评测流程，并已发布测试集答案以支持本地评测，同时收录 EvalScope 作为社区维护的第三方评测工作流。

  • 生成：brave-plum-co/leonardo-ai-desktop · 476 star · 首次收录
    这是一个面向 Windows 10/11 x64 的 Leonardo AI 离线独立部署包，由独立维护者打包发布，主要服务于隔离网络的设计工作站、带宽受限的实验室环境以及需要批量复现安装的团队。它把运行时、模型缓存加载器、资源管线和本地渲染依赖整合进单一分发包，免去首次启动时在线拉取模型，并同时支持便携模式与常规安装模式。材料还提到其覆盖文生图、微调模型、含局部重绘与外扩的画布编辑器、实时生成及图生动态等能力。

3D 与电子设计

  • 打印与建模：earthtojake/text-to-cad · 26407 star · 持续跟踪
    text-to-cad 是一个用 Python 开发的 AI 辅助实体产品设计仓库，目标是让用户通过智能体以文本需求生成零件与装配体的三维模型。它把模型写成基于 build123d 和 OpenCASCADE 的 Python 脚本，可导出 STEP、STL、3MF、GLB 及用于激光/水刀切割的 DXF 轮廓与展开图，并支持机构关节与动画、CAD 查看器实时展示，以及面向制造检查、3D 打印、钣金和 CNC 服务的连接；另含基于 KiCad 的电路板原理图相关能力。

量化交易

  • 综合：gbeced/pyalgotrade · 4678 star · 首次收录
    PyAlgoTrade 是一个事件驱动的 Python 算法交易库，最初侧重回测，也可通过 Bitstamp 进行比特币的模拟交易与实盘交易。它支持市价、限价、止损和止损限价订单，可读取 CSV 格式的各类时间序列数据，并提供技术指标与过滤器、Sharpe 比率和回撤分析等绩效指标、Twitter 实时事件处理、事件分析器以及 TA-Lib 集成。该项目已废弃且不再维护，README 建议关注 Basana 等替代项目。
