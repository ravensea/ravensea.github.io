GitHub 趋势日报 2026-11-01

Author: Ravensea Date: 2026年11月1日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：vrwallace/Insta360-Link-1-and-2-Controller-for-Linux · 33 star · 首次收录
    这是一个用 Free Pascal / Lazarus 编写的 Linux 应用，为 Insta360 Link 与 Insta360 Link 2 摄像头提供官方仅限 Windows/Mac 的 Link Controller 软件的完整替代。它通过 V4L2 与 UVC 扩展单元控制摄像头，支持标准 PTZ、图像、白平衡、曝光、对焦等调节，以及 AI 追踪、DeskView、白板、俯拍、预设位和云台复位等专有模式，并内置基于 MJPEG/YUYV 的实时预览。

  • 电子：openmv/openmv · 2891 star · 持续跟踪
    OpenMV 是开源机器视觉项目，提供可用 Python3 编程的摄像头模块，面向初学者和研究者降低机器视觉与嵌入式 AI 的开发门槛。其固件包含丰富的图像处理库，支持图像滤波、特征检测、颜色追踪、二维码与条形码解码、AprilTag 识别以及 GIF/MJPEG 录制与流传输，并支持 TensorFlow、ST Edge AI 及基于 ARM Ethos-U55 和 ST Neural-ART 的 NPU 加速。最新一代包括基于 STM32N6 的 OpenMV-N6 和基于 Alif Ensemble E3 的超低功耗 OpenMV-AE3，后者可在 0.25 W 功耗下以 30 FPS 运行 YOLO 模型。

  • 算法：worldbench/awesome-event-camera-vision · 11 star · 持续跟踪
    这是面向事件相机视觉研究的综述仓库，以 TeX 撰写，围绕“大模型时代的事件相机视觉”梳理该领域的研究脉络。它主要服务于希望快速了解事件相机感知与重建方向的研究者，目录覆盖目标检测、语义分割、深度与光流估计、目标跟踪、动作识别与姿态估计，以及事件到视频重建等主题，并按 CNN/RNN/图方法、Transformer/注意力、SNN 等路线细分。

视觉、世界模型与运控

  • 世界模型：deeplethe/utopia · 8652 star · 持续跟踪
    Utopia 是 deeplethe 开源、以 Rust 构建的企业级世界模型（world model）项目，仓库自述为“全球首个开源企业世界模型”。材料未具体说明其解决的问题、目标用户及关键技术能力，仅能从 README 结构看到哲学、快速开始、特性与路线图等章节，以及 Apache 2.0 许可和 GHCR 容器镜像等工程配套信息。

  • 视觉运控：starVLA/starVLA · 3892 star · 持续跟踪
    StarVLA 是一个面向通用机器人研究的开源视觉-语言-动作（VLA）模型开发代码库，采用类似乐高的模块化设计，将模型、数据、训练器、配置和评估等功能组件按自顶向下、高内聚低耦合的原则分离，支持即插即用、快速原型开发和独立调试。它旨在为研究者提供集成与探索前沿 VLA 技术的平台，并作为 StarVLA、StarVLA-α 和 VLAct 等团队工作的官方实现。

视觉算法

  • 理解：openclaw/Peekaboo · 5421 star · 持续跟踪
    Peekaboo 是一个用 Swift 编写的 macOS 命令行工具与可选 MCP 服务器，也提供菜单栏应用，用于截取单个应用或整个系统的屏幕截图，并可通过本地或远程 AI 模型进行可选的视觉问答。它面向需要让 AI 代理“看见”屏幕并执行原生 UI 自动化的研究者与开发者，支持屏幕捕获、辅助功能检查与原生 UI 自动化，既可单独使用，也能让内置代理规划多步任务，或将同一套工具集暴露给 MCP 客户端。

  • 生成：NVlabs/Sana · 9730 star · 持续跟踪
    NVlabs/Sana 是一个用 Python 实现的图像合成仓库，核心是线性扩散 Transformer（Linear Diffusion Transformer），面向高分辨率图像生成研究。它主要解决高效高分辨率图像合成问题，为研究者提供 SANA 系列模型与相关工具。材料还显示其覆盖 SANA-1.5、SANA-Sprint、SANA-Video 等多个变体，并提供文档、演示与 HuggingFace 等资源入口。

3D 与电子设计

  • 打印与建模：nanassound/mnft · 38 star · 持续跟踪
    mnft 是一个用 Elixir 编写的文本到 CAD 工具，用户以自然语言描述零件，由语言模型生成 CAD 代码，再经受控引擎执行，输出 STL、STEP 文件及可在浏览器中旋转查看的 3D 预览。其核心 mnft_cad 为纯 Elixir/OTP 实现，包含可插拔引擎（build123d、OpenSCAD）、可插拔存储（默认 ETS 表加 fsync 日志）以及自带密钥的多提供商 LLM 接入，不依赖 Web 框架、认证层或数据库服务器。配套的 Python 与浏览器运行时分别在静态检查、rlimits 和硬性时限下执行 build123d 代码，或通过 replicad 在 WebAssembly 中运行 OCCT 8 内核，并提供 Phoenix、无头及纯浏览器三种参考示例。

量化交易

  • 综合：QuantConnect/Lean · 22331 star · 持续跟踪
    QuantConnect/Lean 是一个用 C# 编写、支持 Python 与 C# 的事件驱动算法交易引擎，面向量化研究者与交易策略开发者。它提供开箱即用的另类数据与实盘交易支持，并采用模块化设计，各组件可插拔、可定制，且为主要插件点附带模型。
