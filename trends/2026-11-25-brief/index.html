GitHub 趋势日报 2026-11-25

Author: Ravensea Date: 2026年11月25日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：Chukwudirogers802/insta360-studio · 63 star · 首次收录
    Insta360 Studio 是面向 Insta360 运动相机与 360 相机用户的 Windows 10/11 桌面端视频编辑软件，用于将相机拍摄的素材处理为可直接分享的普通平面视频。它主要解决 360 素材的拼接、重构图与稳定化问题：可将双镜头画面拼接为等距柱状投影帧，通过关键帧在球面内平移、俯仰和缩放完成重构图，并借助 FlowState 防抖与时间线剪辑进行修剪、分割和分层，最终按源相机能力导出最高 8K 的 MP4。该软件适合希望比手机应用获得更多控制权的运动拍摄、旅行、Vlog、房产与无人机创作者，并支持素材保留在本机、便于在 Premiere 或 DaVinci Resolve 等流程中继续使用。

  • 电子：Lanxin-MRDVS/CameraSDK · 25 star · 持续跟踪
    CameraSDK 是面向迈尔微视（MRDVS）3D 工业相机及相机模组的开发套件，提供运行时库、C/C++ 头文件、Python 包、C# 封装示例以及 ROS/ROS 2 工作空间，支持 Windows 与 Linux 平台。它主要解决将 MRDVS 视觉硬件集成到工业视觉与机器人系统时的设备发现与打开、数据流启停、RGB/深度/幅值/点云/激光点/IMU 等数据读取、相机参数配置以及 ROS/ROS 2 节点发布等问题。套件还包含单相机、多相机、回调采集、托盘定位、避障、视觉定位等示例流程，便于研究者快速接入与验证。

  • 算法：valefleur/EE513_Project3 · 0 star · 首次收录
    这是一个处于提案阶段的括弧曝光 HDR 处理流程项目，目标是对齐 RAW 帧、用加权平均合并为线性辐照图，并做全局与局部色调映射，同时量化相对单帧可恢复的动态范围档数。它面向计算摄影研究者，使用 iPhone 固定 ISO、变化快门的 DNG 括弧曝光数据，并以 Mertens 曝光融合和最佳单帧作为基线，配合动态范围与噪声评估；目前尚无 Project 3 拍摄数据，对齐将复用尚未完成的 Project 2 连拍对齐代码。

视觉、世界模型与运控

  • 世界模型：datawhalechina/learn-world-model · 501 star · 首次收录
    这是一个关于世界模型的学习课程仓库，采用 TypeScript 实现，面向希望系统理解并动手构建世界模型的研究者与学习者。课程以“通过构建来学习”为主线，覆盖从潜在动力学直觉到可运行的仿真、规划与评估系统，包含六讲内容与六个配套项目，涉及状态估计与编码、RSSM 等动力学架构、规划控制、世界模型诊断以及面向机器人控制的动作模型等主题。项目部分提供训练 VAE 编码器、构建 RSSM 动力学模型、训练 Dreamer 智能体、替换动力学骨干、搭建评估仪表盘和反事实动作条件世界模型等实践。

  • 视觉运控：robfiras/loco-mujoco · 1496 star · 持续跟踪
    LocoMuJoCo 是一个基于 MuJoCo 的模仿学习基准，面向全身控制研究，提供四足、人形及（肌肉）骨骼人体模型等多类环境及配套数据集，也支持自定义奖励函数用于纯强化学习。其亮点包括 MuJoCo 单环境与 MJX/MJWarp 并行环境支持、单文件 JAX 算法（SuperMimic、PPO、GAIL、AMP、DeepMimic）、JIT 编译的快速训练、动作捕捉数据重定向与机器人间重定向、基于 JAX 的轨迹比较指标、域与地形随机化，并可通过 LocoMuJoCo Real 在 AgiBot X2 Ultra 和 Unitree G1 上部署。

视觉算法

  • 理解：MugheesMehdi07/langvio · 406 star · 持续跟踪
    Langvio 是一个 Python 库，用于连接语言模型与视觉模型，让用户用自然语言对图像和视频进行视觉分析。它主要面向需要视频理解、目标检测与上下文分析的研究者，核心由 Qwen-VL 驱动查询解析、目标定位与解释生成，并支持图像和视频多模态输入。其能力亮点包括默认通过 OpenAI 兼容接口调用、无密钥时可回退到本地 Qwen2.5-VL 权重，保留 YOLO-World v2 与 ByteTracker 的开放词汇检测路径，以及提供属性匹配、视频跟踪摘要、计数与空间关系分析、可视化标注输出和 Flask Web 界面。

  • 生成：hatchlight/hatchlight · 6 star · 首次收录
    Hatchlight 是一个用 TypeScript 开发的开源、本地优先的图像与视频生成客户端，面向需要在多个 AI 模型间进行对比实验的研究者。它支持将同一提示词同时发送给多个模型并排生成，展示各自耗时与成本，既可在本机显卡上免费离线运行，也能用用户自己的密钥直接调用云端服务，无需账号且无遥测。其亮点在于自动检测硬件并选择适配的模型版本、下载校验文件后本地运行，以及通过 MCP 服务器等方式与外部工具集成。

量化交易

  • 综合：vincent212/kaspar-hft · 69 star · 首次收录
    Kaspar-hft 是一个用 C++20 编写的生产级高频交易系统，同时提供能感知队列位置的订单簿模拟器，面向需要统一回测与实盘代码路径的研究者。它通过可插拔的行情与下单会话支持多市场，已内置 CME MDP3 行情、iLink 3 下单和 TT FIX 4.4 路由，并覆盖 PCAP 回放、POV 执行及 Binance、Coinbase、Hyperliquid 的加密模拟。其基于无锁、低开销的 actor 框架，使同一策略代码可用于回放、纸面交易和实盘；FPGA actor 与按场馆规范自动生成适配器尚在开发中。
