GitHub 趋势日报 2026-11-04

Author: Ravensea Date: 2026年11月4日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：93won/360_visual_inertial_odometry · 184 star · 持续跟踪
    该仓库是面向360°全景相机的视觉-惯性里程计项目，现已成为OpenVIO框架的一部分，后者支持360°等距柱状投影、针孔和鱼眼相机。原代码保留在本仓库历史记录中，建议使用者转向OpenVIO。

  • 电子：friendlytofu/diy-dual-cmos-camera · 1 star · 首次收录
    这是一个基于两块 ESP32-WROVER-E 与 OV2640 传感器搭建的双摄像头手持相机原型，配有 2 英寸 LCD 本地预览、双 microSD 卡存储、按键与状态指示灯，并提供设备自托管网页用于浏览和下载两张卡中的照片。仓库面向复现该 DIY 硬件的研究者，包含物料清单、接线设计与图示、可打印外壳 STL 与装配说明、U1 外向相机和 U4 自拍/控制器的 Arduino 固件，以及网页源码与设备 API 说明。材料同时说明，组合接线、外壳装配、供电、全分辨率下载和预览性能等仍需在整机上验证。

  • 机械：yzytz17/1.5-joint-module · 53 star · 首次收录
    这是一个超低成本机器人关节模块，将约1.5美元的四层FOC驱动板嵌入1503无刷云台电机，并搭配全3D打印的高减速比精密齿轮箱，面向需要低成本执行器规模化的研究者与开发者，可用于六自由度机械臂、四足机器人或云台等场景。其亮点在于以原型价格实现板内集成驱动与单级10:1减速，在不牺牲减速比和定位分辨率的前提下压低成本，并开放PCB Gerber、驱动固件、SolidWorks CAD和可打印STL。仓库目前仍在完善中，部分缺失内容以TODO标注，占位数值尚未验证。

  • 算法：mickeykang16/Ev3DOD · 37 star · 持续跟踪
    Ev3DOD 是 CVPR 2025 Highlight 论文《Ev-3DOD: Pushing the Temporal Boundaries of 3D Object Detection with Event Cameras》的官方实现，基于 Python，面向使用事件相机进行 3D 目标检测的研究者。它主要解决传统帧相机在盲时区间难以检测的问题，采用两阶段训练：第一阶段不使用事件数据的常规框提议，第二阶段将事件数据与其他传感器模态融合，以支持盲时区间内的检测。仓库已发布 Ev-Waymo 与 DSEC-3DOD 数据集及训练和评估代码，其中 DSEC-3DOD 由作者手工标注。

视觉、世界模型与运控

  • 世界模型：lightly-ai/lightly · 3827 star · 持续跟踪
    LightlySSL 是一个面向计算机视觉的 Python 框架，用于在图像上开展自监督学习与潜在世界模型训练，适合需要利用无标注图像学习表征或建模场景动态的研究者。它提供自监督学习与潜在世界模型相关能力，并已支持 LeJEPA 自监督学习方法及基于 LeWM 的世界模型训练与规划教程。

  • 视觉运控：Unity-Technologies/ml-agents · 19817 star · 持续跟踪
    Unity ML-Agents Toolkit 是一个开源项目，使游戏和仿真环境可用于训练智能体。它主要面向需要构建训练环境的研究者，支持使用深度强化学习和模仿学习来训练智能体。项目以 C# 实现，并提供包文档，涵盖安装、版本兼容、功能、教程与 API 参考等内容。

视觉算法

  • 理解：Neywa-Labs/mlx-vlm · 5790 star · 首次收录
    MLX-VLM 是一个基于 MLX 的 Python 包，用于在 Mac（Apple Silicon）上对视觉语言模型进行推理和微调，支持文本、图像、视频和音频输入。它面向需要在本地运行和微调多模态模型的研究者，提供命令行界面、Gradio 聊天界面、FastAPI 服务端以及投机解码、连续批处理、前缀缓存、KV 缓存量化、视觉特征缓存和分布式推理等能力。

  • 生成：enricoros/big-AGI · 7164 star · 持续跟踪
    Big-AGI 是一个用 TypeScript 编写的 AI 套件，基于先进模型提供 AI/AGI 功能，面向需要高级 AI 交互能力的研究者与开发者。它主要解决多模型对话与多模态 AI 使用需求，提供 AI 人格、AGI 函数、Beam 多模型聊天、文本生成图像、语音、响应流式传输、代码高亮与执行、PDF 导入以及面向开发者的预设等功能。该套件支持本地部署或云端部署。

3D 与电子设计

  • 打印与建模：armpro24-blip/cad-cae-copilot · 86 star · 持续跟踪
    CAD/CAE Copilot 是一个面向 AI 智能体的 AI 原生 CAD/CAE/CAX 工作台，用 Python 实现，支持从工程规格文本生成可编辑、可验证的真实 CAD 模型并延伸到 CAE 流程。它主要解决 AI CAD 工具只停留在生成图片、无法产出可复现工程产物的问题，面向需要文本转 CAD/CAE 的研究者与工程用户。关键技术能力包括基于 build123d/OpenCASCADE 的真实几何、STEP/STL/GLB 导出、命名零件与可编辑参数、稳定拓扑指针、确定性评审，以及 MCP 服务器工具，并将全部产物保存在可复现的 .aieng 包中。

量化交易

  • 综合：rootSunc/CNEquity · 933 star · 首次收录
    CNEquity 是一个开源的中国 A 股本地数据湖，用 Python 实现，将沪深股票行情、财务与期货数据、资金流向、公告、指数行业及宏观等数据集落到本地 Parquet，面向量化研究、量化交易与回测。它免注册、免 Token、可自托管，内置复权与历史成分、保留退市股、财报按公告日严格 PIT，并提供行级溯源与增量续跑，同时通过 MCP 原生支持让 AI 客户端直接查询 A 股数据。
