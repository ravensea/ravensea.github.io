GitHub 趋势日报 2026-11-06

Author: Ravensea Date: 2026年11月6日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：jamakr4/MG4-360-Camera-App · 43 star · 持续跟踪
    这是一个面向 MG4 EV（AAOS 9、2026 款改款前车型）的社区改装应用，用更简洁的平铺视图替代原厂启动器叠加界面，并取消自动关闭的速度阈值。它主要解决原厂 360° 影像在高速下盲区监测受限、全屏接管等问题，提供转向灯摄像头叠加、原生四摄像头行车记录仪和数字后视镜等能力。项目基于 Java 开发，并涉及 C++、OpenCV 与 Gradle，目前仍在开发中。

  • 电子：christianrauch/camera_ros · 171 star · 持续跟踪
    这是一个基于 C++ 的 ROS 2 节点，通过 libcamera 为多种相机提供支持，包括 V4L2 设备和树莓派相机模块。它主要面向需要在 ROS 2 环境中接入 libcamera 兼容相机的开发者与研究者，解决相机接入与驱动适配问题。该节点依赖 libcamera 0.1 或更高版本，可通过 ROS 二进制包安装，也支持从源码构建，并可与 libcamera 在 colcon 工作区中一起编译。

  • 机械：Source-Robotics/Differential-robot-wrist · 370 star · 首次收录
    这是一个面向机器人腕部的开源 3D 打印差速机构，由两个云台电机经同步带驱动打印的锥齿轮，用于验证该差速机构并服务于后续机器人设计。项目提供 BOM、打印文件、装配图片和示例代码，配套 Spectral Micro BLDC 驱动器（同一 CAN 总线）及 Python 库，便于研究者搭建与测试。

  • 算法：gohakushi1118/Intro-to-Computer-Vision-and-Computational-Photography · 1 star · 持续跟踪
    这是一个以 Jupyter Notebook 为主要载体的计算机视觉与计算摄影入门课程资料仓库，对应 UCB CS 课程内容。它围绕图像处理与视觉建模的实践项目组织，涵盖 Prokudin-Gorskii 照片集合彩色化、滤波器与频率、人脸变形与照片集合建模、自动拼接与照片马赛克，以及基于神经网络的人脸关键点检测。

视觉、世界模型与运控

  • 世界模型：Junchao-cs/SolarWM · 881 star · 持续跟踪
    SolarWM 是一个面向交互式世界模型的开源框架，提供开放数据、可扩展训练、长时程视频生成与实时部署的代码，包含 SolarWM 与 SolarRenderer 两个项目。它主要服务于长时程视频世界模型的研究与训练，配套公开数据集和模型权重，并附有训练、推理与部署文档。

  • 视觉运控：lagadic/visp · 939 star · 持续跟踪
    ViSP 是一个用 C++ 实现的开源视觉伺服平台，面向从事视觉伺服研究与机器人视觉应用的研究者。它主要解决视觉伺服相关算法的开发与集成问题，并提供跨平台构建支持，覆盖 Ubuntu、macOS、iOS、Windows 以及 ROS2 多个发行版，同时包含 Valgrind、Sanitizer 和代码覆盖率等质量保障流程。

视觉算法

  • 理解：sotayang/LiveStar · 163 star · 持续跟踪
    LiveStar 是 NeurIPS 2025 论文的官方代码仓库，面向实时在线视频理解，提供 LiveStar 与期刊扩展 LiveStarPro 两个模型的代码、数据和流程，二者可在同一推理框架下运行以便直接对比。它主要解决 Video-LLM 处理连续视频流时过度依赖学习 EOS 令牌、导致推理表现不佳的问题，通过 SCAM 与 SVeD 构建响应—静默训练与推理框架，且不损害基础视频理解能力。LiveStarPro 进一步引入树状分层记忆（TSHM）以支持长时程视频流，并加入流式 KV Cache 加速推理，二者均在相同的 LiveStar-8B 权重上于推理阶段实现。

  • 生成：silverdugongenhance/PromptReel · 151 star · 首次收录
    PromptReel 是一款面向 Windows 10/11 的免费桌面应用，可将一句文字提示在本机生成短视频片段，采用 Wan 2.2 实现本地 AI 文生视频。它主要解决云端生成工具需要积分、订阅和排队的问题，让提示词与成片都留在用户电脑上。应用支持宽屏、竖屏或方形画幅，可选择时长、画质与镜头运动，后台渲染并导出 MP4，片段会连同提示词一并保存以便修改重跑。

3D 与电子设计

  • 打印与建模：Masoudjafaripour/Vibe_CADing · 13 star · 持续跟踪
    Vibe-CADing 是一个面向文本到 CAD 设计流程的 Python 仓库，核心思路是“几何即代码”：由大语言模型把文本提示写成 CadQuery/build123d 程序或 GLSL 符号距离函数，执行后把错误回传给模型修复。它主要服务于需要从文本生成、检索和复用三维 CAD 部件的研究者，提供体素扩散/VAE/VQ-VAE/自回归生成、PixelCNN 风格二维 CAD 布局生成、基于开源 CAD 库的检索增强生成，以及几何反馈与可制造性评分。其亮点是 Planner/Retriever/Generator/Critic 多智能体编排形成的迭代反馈工作流，并支持 B-rep/STEP、GPU 渲染隐式曲面和文本到三维角色动画等可运行路径。

量化交易

  • 综合：freqtrade/freqtrade · 56508 star · 持续跟踪
    Freqtrade 是一个用 Python 编写的免费开源加密货币交易机器人，面向需要自动化交易与策略研究的研究者，支持多家主流现货及期货交易所，并可通过 Telegram 或 WebUI 控制。它提供回测、绘图和资金管理工具，并支持通过机器学习进行策略优化，便于在实盘前进行策略验证与评估。
