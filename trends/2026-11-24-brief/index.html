GitHub 趋势日报 2026-11-24

Author: Ravensea Date: 2026年11月24日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：vulture-s/arkiv · 81 star · 持续跟踪
    arkiv 是一个本地优先的媒体资产管理器，面向个人 DIT 和小型团队，用于解决消费级 DAM 无法读取索尼 XAVC 侧车文件、FX 系列及 Insta360/GoPro Max 等 360 素材元数据的问题。它通过 FFmpeg、ChromaDB 和本地 LLM 为素材生成转录、视觉标签、氛围、能量与剪辑位置等 AI 元数据，支持中、日、英多语言语义搜索，并提供 Resolve 插件、EDL/FCPXML 导出及 API/MCP 接口。

  • 电子：amd/mini-isp · 154 star · 持续跟踪
    Mini-ISP 是面向 AMD FPGA、完全用 Verilog RTL 在可编程逻辑中实现的小型开源图像信号处理器，用于把相机传感器 RAW 数据转换为可供显示、后续处理或存储的图像，为缺少硬化 ISP 的 FPGA 与 SoC 提供 ISP 方案。其设计目标是在占用尽量少 PL 资源的前提下实现高吞吐、低延迟，并保证输出结果正确、图像质量对多数应用可接受。

  • 机械：FerdiCildiz/pocket-plus · 18 star · 持续跟踪
    Pocket+ 是一款免费的 macOS 应用（提供可选 Pro 升级），用于从 Mac 控制 DJI Osmo Pocket 2、3、4 和 4P，可录制、拍照、操控云台、变焦和进行人脸追踪。它主要解决 DJI Mimo 没有 Mac 版的问题，适合把 Pocket 放在 Mac 旁作为桌面摄像头使用的研究者。其能力亮点包括 USB-C 实时预览与录制（H.264/HEVC）、人脸追踪与群体追踪、直方图与网格/地平线辅助，以及 Pro 版提供的最高 4K 录制、场景保存、自动构图、竖屏视频和曝光/色彩调整。

  • 算法：zaper11/Computational_Photography · 0 star · 首次收录
    这是 GIST 2026 秋季计算摄影课程的作业仓库，使用 Python 编写，主要面向修读该课程的学生和研究者，用于存放与查阅课程作业代码。现有材料仅包含仓库标题和课程作业说明，未提供具体作业内容、实现方法或技术亮点，因此无法进一步概括其功能与能力。

视觉、世界模型与运控

  • 世界模型：naver-ai/seoul-world-model · 701 star · 首次收录
    Seoul World Model（SWM）是面向城市尺度视频生成研究的自回归世界模型官方代码，以真实首尔为场景基础。它通过在约44万张首尔街景图像、真实驾驶视频和合成城市数据上微调预训练视频世界模型，解决在给定坐标、相机动作和文本提示时生成真实城市场景视频的问题。其关键能力是检索增强生成：生成时从参考数据库检索附近街景图像，并以其几何与外观线索作为条件，从而渲染跨越数公里真实城市景观的忠实视频。

  • 视觉运控：StanfordVL/BEHAVIOR-1K · 1808 star · 持续跟踪
    BEHAVIOR-1K 是一个面向具身智能研究的综合仿真基准，用于在 1000 项日常家务活动中训练和评估智能体，任务涵盖清洁、烹饪与整理等，均选自真实人类时间使用调查和偏好研究。该仓库为单体式代码库，提供训练与评估所需的全部组件，并配有支持模块化安装的安装脚本，可按需只安装所需部分。

视觉算法

  • 理解：Tencent/WeMM-Video · 133 star · 首次收录
    WeMM-Video 是腾讯微信视觉团队开源的全模态基础模型系列，面向中英双语场景，可接收文本、图像、音频和视频输入并生成文本回复，视频输入还能结合原始音轨进行联合音视频理解与推理。该系列包含 2B、4B、9B 稠密模型和 35B-A3B 混合专家模型，提供快速直接响应的 Instruct 模式与支持显式多步推理的 Thinking 模式，并在通用音频、图像和文本能力上保持较强表现。模型经渐进式预训练和多阶段后训练，使用约 1.2 万亿多模态 token 训练；据材料，35B-A3B 在全模态视频理解上取得开源最优表现。

  • 生成：fujc683/seedance-2-5-flash-api · 438 star · 显著涨星
    该仓库是 Seedance 2.5 Flash 文生视频 API 的调用说明，面向需要接入该模型的研究者与开发者，整理了异步任务接口的请求方式、参数规则与常见错误。内容涵盖通过提交生成任务获取 task_id 后轮询结果、时长 4–30 秒与多种画面比例及 480p/720p 分辨率限制（1080p 会返回 400），并给出按输出秒数计费的价格与实测成本。

3D 与电子设计

  • 打印与建模：SSSSSia/CadAgent · 9 star · 持续跟踪
    CadAgent 是一个基于 LLM Agent 的 FreeCAD 工作台插件，让研究者用中英文自然语言描述来生成和修改 3D 机械模型（text-to-cad）。它通过 ReAct 循环完成推理、生成 CadQuery 风格代码、执行与自纠错，并内置质量门禁、参数化重放、多文档装配、STEP/IGES/STL/OBJ 导出及视口截图与参考图分析等能力，减少建模中的常见布尔运算与几何错误。

量化交易

  • 综合：vnpy/vnpy · 46474 star · 持续跟踪
    VeighNa（vnpy）是基于 Python 的开源量化交易系统开发框架，面向私募基金、证券与期货公司等机构及量化研究者，支持在 Windows、Linux、macOS 上进行策略与模块的二次开发。4.0 版本新增 vnpy.alpha 模块，提供多因子机器学习策略的一站式开发、投研与实盘交易能力，涵盖因子特征工程（含 Alpha 158 因子集）、标准化模型训练（Lasso、LightGBM、MLP）、截面与时序策略构建以及集成回测的投研流程管理。
