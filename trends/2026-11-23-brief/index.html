GitHub 趋势日报 2026-11-23

Author: Ravensea Date: 2026年11月23日 Category: Trends

每个子方向只保留一项代表仓库，按下列优先级挑选：

  1. 已出现在 GitHub 全球「今日」趋势榜的优先；
  2. 其次看本跟踪器状态：首次收录 > 显著涨星 > 持续跟踪；
  3. 同优先级再按 star 总数从高到低；
  4. 同一 GitHub「This week」近 7 天内，更早日报已出现过的仓库不再入选；同日各子方向之间也不重复。

影像与相机形态

  • 综合：jagjordi/insta360-autostitcher · 29 star · 首次收录
    这是一个用 Python 编写的 Insta360 视频自动拼接工具，会监控指定目录中的 *.insv 文件，并自动将它们拼接为 360 视频。它面向需要批量处理 Insta360 素材的用户，依赖需自行申请的 Insta360 MediaSDK，通过 Docker Compose 部署 Flask 后端（含拼接 worker 与缩略图生成）和 React 前端，运行数据统一存放在可配置的存储根目录下。

  • 电子：10x-Engineers/Infinite-ISP · 415 star · 持续跟踪
    Infinite-ISP 是一个面向硬件 ISP 全流程开发的全栈平台，核心是用 Python 实现的应用级相机 ISP 流水线模块，算法覆盖从简单到复杂。它主要服务于 ISP 算法开发与硬件实现研究者，提供定点参考模型、优化 RTL 设计、面向 Xilinx Kria KV260 的 FPGA 集成框架与固件，以及可针对不同传感器和应用调参的独立 Python 调优工具。平台还包含 Linux 软件方案（驱动与自定义应用开发栈），并配套自动化块级与多块级测试框架以保障设计位精确。

  • 机械：SpaceMonkeyAlfa/PAL9000-Desktop-Robot · 22 star · 持续跟踪
    PAL9000 是一个用 Python 驱动的 2 自由度桌面云台机器人项目，由 Pico W 控制云台，并借助旧安卓手机作为“大脑”完成本地处理。它面向想搭建低成本桌面机器人原型的研究者与爱好者，目标是实现人脸跟踪、用眼和颈部跟随人脸、实时显示表情、语音转写，以及把任务转发给各类 API 或 AI 服务。项目以开源代码和博客教程形式提供搭建说明，当前运行依赖安卓手机（Termux）、摄像头、Mac/MacBook、Pico W 和 2 自由度云台等多设备协作。

  • 算法：oindreechatterjee/cs180 · 0 star · 首次收录
    该仓库是 cs180 的课程项目代码库，主题为计算机视觉与计算摄影，主要面向学习或研究该方向的研究者参考。材料仅说明其语言为 HTML，未给出具体技术方案或功能细节，因此无法确认其解决的问题与能力亮点。

视觉、世界模型与运控

  • 世界模型：NVlabs/LongLive · 2895 star · 持续跟踪
    NVlabs/LongLive 是 NVIDIA 面向长视频生成、世界模型与具身世界动作模型的研究基础设施，仓库按项目分目录组织，各项目自带代码、文档与模型权重。它主要服务于需要训练或部署长视频生成模型、以及在 YAM、Franka、Unitree G1 等平台上训练评估机器人策略的研究者。关键技术能力包括：Long-WAM 的长上下文世界动作建模，LongLive-Plug 的一次性蒸馏并跨下游模型复用，LongLive2.0 的 NVFP4 量化与序列并行训练推理，以及 LongLive1.0 的实时交互式长视频生成。

  • 视觉运控：dexmal/dexbotic · 3239 star · 持续跟踪
    Dexbotic 是一个基于 PyTorch 的开源视觉-语言-动作（VLA）开发工具箱，面向具身智能研究，提供预训练、微调、推理与评估的统一流程。它内置 π0、CogACT、OFT、MemVLA 等主流策略的环境配置与优化预训练模型，并采用分层配置、工厂注册和入口调度的模块化架构，便于改配置、换模型或加任务。该工具箱支持云端与本地训练，并为 UR5、Franka、ALOHA 等机器人提供统一训练数据格式和部署脚本。

视觉算法

  • 理解：MMMU-Benchmark/MMMU · 601 star · 持续跟踪
    该仓库是 MMMU 与 MMMU-Pro 两篇论文的官方评测代码，面向研究者评估多模态模型在需要大学水平学科知识与审慎推理的多学科任务上的表现。MMMU 包含约 1.15 万道来自考试、测验和教材的多模态题目，覆盖六大核心学科、30 个学科和 183 个子领域，涉及图表、示意图、地图、表格、乐谱和化学结构等 32 种异构图像类型；MMMU-Pro 则是更稳健的评测版本。仓库提供相应评测流程，并已发布测试集答案以支持本地评测，同时收录 EvalScope 作为社区维护的第三方评测工作流。

  • 生成：Aroralayla99/capcut-seedance-win · 371 star · 首次收录
    这是一个面向 Windows 10/11 的 CapCut Seedance 参考与安装指南，所介绍的工具用于把文本提示和静态图片生成短视频片段，并支持图像动画与运动效果调节。它面向希望快速产出社交素材的新手，以及需要快速概念预览或 B-roll 草稿的专业人士，生成结果可接入 CapCut 编辑时间线继续调整。材料提到的亮点包括提示词驱动的工作区、运动控制、预设视觉效果和 GPU 加速渲染，整体流程支持反复生成变体。

3D 与电子设计

  • 打印与建模：earthtojake/text-to-cad · 27167 star · 持续跟踪
    text-to-cad 是一个用 AI 设计实体产品的 Python 项目，通过插件形式接入 Claude Code、Codex、Cursor 等多种智能体，让用户用自然语言请求零件或装配体。智能体据此编写基于 build123d 与 OpenCASCADE 的 Python 脚本，生成 STEP、GLB、STL、3MF 等三维模型及用于激光和水刀切割的 DXF 轮廓与展开图，并支持机构关节与动画、在查看器中实时显示。它还提供面向制造检查、绘图以及连接 3D 打印、钣金和 CNC 服务的本地工作流，并包含电路板相关能力。

量化交易
